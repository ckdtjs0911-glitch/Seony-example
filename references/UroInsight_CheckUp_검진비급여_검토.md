# UroInsight CheckUp 건강보험·검진 비급여 검토 정리

## 0. 한 줄 결론

건강검진 목적으로 수검자가 촬영한 CT 영상을 UroInsight CheckUp으로 분석하는 경우, **행위수가(신의료기술 등재) 경로가 아니라 건강검진 비급여**에 해당한다. 심평원에 보험 등재·등록할 필요가 없으며, 검진기관이 가격을 정하고 수검자에게 미리 알린 뒤 전액 본인부담으로 받는다.

## 2. 배경: 한국 디지털의료제품의 건강보험 진입 경로

### 2.1 기본 원칙
- 식약처 허가(신고)를 받았다고 건강보험이 자동 적용되지 않는다.
- 허가 이후 별도의 의료기술평가와 건강보험 등재 절차를 거쳐야 한다.

### 2.2 세 가지 진입 경로

| 경로 | 흐름 | 특징 |
| --- | --- | --- |
| ① 일반 경로 | 식약처 허가 → 심평원 요양급여대상·비급여대상 여부 확인(기존기술 여부) → 신의료기술이면 한국보건의료연구원(보의연) 신의료기술평가 → 심평원 전문평가위원회 → 건강보험정책심의위원회(건정심) → 복지부 고시 | 기존기술로 판정되면 기존 행위 코드·수가를 그대로 사용(별도 수가 없음) |
| ② 혁신의료기술 통합심사 트랙 | 식약처·심평원·보의연 동시 심사(약 390일 → 80일) → 임시등재(임시코드·수가 부여) → 실사용 증거(RWE) 축적 → 신의료기술 재평가 → 정식 등재 | 디지털·웨어러블, 인공지능·빅데이터 기술 대상. 임시등재 기간에는 선별급여(본인부담 90%) 또는 한시적 비급여 |
| ③ 평가유예·시장 즉시진입 | 허가 신청 때 임상평가자료 제출 → 평가유예 공고 → 허가와 동시에 비급여 판매 | 평가·등재 절차는 계속 진행. 허가 단계 임상자료가 전제 |

### 2.3 수가 산정
- 기존 유사 의료행위의 수가를 준용하고, 비교 대상이 없으면 상대가치점수로 산출한다.
- 디지털치료기기(DTx)는 처방료 + 효과평가료(16,130원 단일) + 기기사용료 구조이다.

### 2.4 2026년 동향
- 임시등재 이후 정식 등재에 적용할 급여 적정성 평가기준과 보상체계는 아직 마련되지 않았다.
- 심평원 위탁연구가 초기 처방 시 의사 행위료 50~100% 가산, 기기사용료 유형별 고정금액 등을 제안했다. 확정 제도가 아닌 연구 제안 단계이다.

### 2.5 혁신의료기기가 아니어도 행위수가가 가능한가
- 가능하다. 행위수가는 의료기술(행위)을 평가하는 제도이고, 혁신의료기기 지정은 빠른 경로 중 하나일 뿐이다.
- 관건은 **기존기술로 판정되느냐**이다.
  - 기존기술이면 절차는 쉽지만 별도 수가가 없다(예: AI 판독보조가 기존 판독료에 흡수).
  - 별도 수가를 받으려면 기존 행위와 구별되는 새로운 행위이면서 임상적 이득이 있음을 입증해야 한다.

## 3. 이 제품에 대한 보험 적용 판단

### 3.1 상황별 적용 여부

| 사용 상황 | 비급여 적용 | 근거·비고 |
| --- | --- | --- |
| 본인 희망 민간 건강검진 CT에 사용 | **가능 (등록 불필요)** | 요양급여규칙 제9조 → 별표2 제3호 가목 법정 비급여 |
| 국가건강검진 CT에 사용 | 해당 없음 | 국민건강보험법 제52조 국가건강검진은 제외. 편입하려면 별도 절차 필요 |
| 진료 목적 CT(환자)에 사용 | 불가 | 사용목적 밖. 별도로 비용을 받으면 임의비급여(환수 대상) |
| 행위수가·급여 등재 | 현재 해당 없음 | 중장기 C안(사용목적 재설계, 등급 상향, 임상 근거 확보, 신의료기술 인정) 이후 검토 |

### 3.2 진료(환자) 비급여·급여가 현재 불가한 이유
1. **사용목적 불일치**: 신고된 대상이 "질환이 의심되지 않는 일반 수검자"이므로 환자 진료에 쓰는 것 자체가 사용목적 밖이다.
2. **기존기술 판정 위험**: ROI를 의료진이 직접 설정하고 정량정보만 주는 구조라, 기존 CT 판독에 포함되는 기존기술로 판정될 위험이 크다.
3. **임상 근거 부재**: 1등급 신고 제품으로 허가 단계 임상자료가 없어 평가유예·시장 즉시진입에 해당하기 어렵다.

### 3.3 중장기 C안 (진료 비급여·급여로 가는 경로)
사용목적을 환자 진료용으로 재설계 → 필요 시 등급 상향·재허가 → 임상 근거 확보 → 심평원 여부 확인에서 신의료기술 판정 → 보의연 신의료기술평가 통과 → 비급여 또는 급여 등재

## 4. 검진 비급여의 법적 근거

### 4.1 근거 구조
```
국민건강보험법 제41조제4항
  → 국민건강보험 요양급여의 기준에 관한 규칙(2026.4.15 시행) 제9조 제1항
     "비급여대상은 별표 2와 같다"
    → 별표 2 제3호: 예방진료로서 질병·부상의 진료를 직접 목적으로 하지 아니하는 경우
      → 가목: 본인 희망에 의한 건강검진
```

### 4.2 해석상 핵심
- 별표2 제3호 가목은 **법에서 이미 비급여로 정해 둔 영역**이다. 별도의 신청·등재 창구가 아니다.
- 따라서 "신청한다"가 아니라 **"해당한다/근거로 삼는다"**가 정확한 표현이다.
- 요양급여규칙 제2조 제2항·제4항(검진 언급), 제15조(별표2 재검토)는 보조 조항이며 검진 비급여를 직접 규정하지 않는다.

### 4.3 성립 전제 조건
1. 수검자가 원해서 받는 **민간 건강검진**일 것 (국민건강보험법 제52조 국가건강검진은 제외)
2. **사용목적 범위**를 지킬 것 (증상 환자·진단 목적 사용 시 적용 안 됨)
3. 청구 주체는 **검진기관**이고, 유로인사이트는 소프트웨어를 공급할 것

---

## 5. 실무 절차

### 5.1 검진기관이 할 일 (등록이 아닌 운영 의무)
1. **항목 편입·가격 책정**: 검진 패키지 항목이나 선택 옵션으로 넣고 가격을 자체 결정한다. 보험 행위코드를 새로 만드는 것이 아니다.
2. **고지·게시 (의료법 제45조)**: 비급여라는 점과 가격을 수검자에게 미리 알리고, 원내와 홈페이지에 게시한다. 검진 동의서·설명에도 포함한다.
3. **비급여 보고 (의료법 제45조의2)**: 보고 대상 항목이라면 심평원에 비급여 가격 현황을 보고한다. **이는 가격 현황 보고이며 보험 등재 절차가 아니다.**
4. **수납**: 수검자에게 전액 본인부담으로 받는다.

### 5.2 보험 등재와 비급여 보고의 차이

| 구분 | 보험 등재 | 비급여 보고 |
| --- | --- | --- |
| 시점 | 사용·청구 전 | 이미 받고 있는 가격을 사후 신고 |
| 성격 | 심평원 심사를 거쳐 항목 인정 | 가격 현황 수집·공개 제도 (심사·승인 없음) |
| 이 제품 | 필요 없음 | 보고 대상 항목이면 검진기관이 수행 |

### 5.3 유로인사이트(제조사)의 역할
- 검진기관에 소프트웨어 공급(판매 또는 건당·월정액 사용료).
- 공급 계약서에 사용목적(일반 수검자 검진용)을 명시한다.
- 마케팅·계약·검진 안내 문구를 "질환이 의심되지 않는 일반 수검자의 예방적·관리적 검진" 범위로 유지한다.

## 6. 권장 사항: 심평원 비급여대상 여부 확인 (의무 아님)

### 6.1 목적
이 사용 방식이 검진 비급여에 해당한다는 공식 근거를 확보해, 임의비급여 시비가 생겼을 때 방어 근거로 쓴다. 등록이 아니라 성격 확인 절차이다.

### 6.2 절차

| 단계 | 내용 |
| --- | --- |
| 1단계: 사전상담 | 심평원에 비공식 상담으로 별표2 제3호 가목 해당 여부 방향을 먼저 확인. 서식 최신본과 신청 주체 적격도 이때 확인 |
| 2단계: 정식 신청 | 아래 표 참조 |
| 3단계: 결과 통보 | "비급여대상(건강검진에 해당)" 회신 시 그 통보서가 근거. 이후 검진기관이 고지·보고 절차로 운영 |

| 항목 | 내용 |
| --- | --- |
| 근거 | 요양급여규칙 제9조의2, 「요양급여대상·비급여대상 여부 확인의 절차와 방법 등에 관한 기준」 |
| 신청 주체 | 요양기관(검진기관·의료기관), 의약관련 단체 등. 제조사 단독 신청은 조문상 애매하므로 검진기관 명의 권장 |
| 신청처 | 건강보험심사평가원장 (의료기기 관련 단서에 해당하면 식약처장 경유) |
| 서식 | 별지 제13호의2서식 「요양급여대상·비급여대상 여부 확인 신청서」 |
| 첨부서류 | ① 제조신고증 및 관련 자료 ② 요양급여대상·비급여대상 여부에 대한 의견서(핵심) ③ 국내외 연구논문 등 참고자료 |
| 처리 기간 | 접수일부터 30일 이내 (심층검토 시 1회 30일 연장) |
| 이의신청 | 결과 통보 후 30일 이내 |

### 6.3 의견서 핵심 논거 (4가지)
심평원이 "신의료기술평가 대상"이나 "기존 CT 판독료에 포함(기존기술)"으로 보면 검진 비급여 경로가 막히므로, 신고증 사용목적을 근거로 다음을 강조한다.
1. **예방진료 해당**: 대상이 질환이 의심되지 않는 일반 수검자이고 목적이 예방적·관리적이므로 별표2 제3호에 해당.
2. **본인 희망 검진**: 별표2 제3호 가목의 본인 희망 건강검진이며 국가건강검진(법 제52조)과 무관.
3. **새로운 진단행위 아님**: 질환을 판단하지 않고 의료진이 설정한 ROI의 정량정보만 제공하므로 신의료기술이 아님.
4. **기존 판독료에 흡수되지 않음**: 예방검진 맥락이므로 기존 CT 판독료에 포함되는 행위가 아님.

※ 의견서 초안(Word)은 별도로 작성되어 있음. 신청인·연락처·날짜·서명 빈칸, 참고문헌 보강 여지 있음.

## 7. 주의사항

1. **사용목적 범위 유지**: 증상 환자나 진단 목적으로 쓰면 사용목적 위반이며, 별도로 비용을 받으면 임의비급여가 된다.
2. **신고서 문구 불일치**: 일반적 주의사항 3-1)은 "**질환 유무와 관계없이** 의료기관 또는 건강검진기관에서 CT 검사를 받은 수검자", 사용목적은 "**질환이 의심되지 않는** 일반 수검자"로 서로 다르다. 심평원이 이를 근거로 "환자 진료에도 쓰는 제품"으로 볼 수 있으므로, 의견서는 사용목적 문구를 기준으로 쓰고 다음 변경신고 때 주의사항 문구를 사용목적에 맞춘다.
3. **진료 CT에의 기회적 분석**: 사용 장소에 의료기관이 포함되어 있어 진료 목적 CT에 분석을 붙일 수는 있으나, 이 경우 수검자에게 별도 비용을 받을 수 없다.
4. **국가검진**: 국가건강검진 CT에는 이 조항이 적용되지 않는다.

## 8. 이해를 돕는 비유

같은 검사라도 **검진 목적이냐, 진료 목적이냐**에 따라 적용 제도가 달라진다.
- 종합검진에서 본인이 원해서 추가하는 뇌 MRI → 검진 비급여(전액 본인부담) → **UroInsight CheckUp의 현재 경로**
- 두통 등 증상으로 진료 후 의사가 처방한 뇌 MRI → 조건에 맞으면 건강보험 급여 → 중장기 C안에 해당

※ 도수치료는 적절한 비유가 아니다. 도수치료는 진단 여부와 무관하게 건강보험상 비급여이며, "보험 적용"으로 느끼는 것은 대부분 실손보험(민간보험) 환급이기 때문이다.

■ 제품 개요
- 적용 대상: 의료기관 및 건강검진기관의 수검자
- 사용목적(신고증 기준): 특정 질환이 의심되지 않는 일반 수검자의 예방적·관리적 차원의 임상적 관리 유도
- 사용 방식: 수검자가 검진 목적으로 촬영한 CT 영상을 본 제품으로 분석

■ 확인을 부탁드리는 사항
